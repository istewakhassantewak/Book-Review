# 📚 Book Review App

A modern book review and reading management web application built with **React.js**, **React Router**, and **Tailwind CSS**. Users can explore books, read detailed reviews, and manage a personal reading list using **localStorage**.

---

## 🚀 Live Demo

🔗 Live Site: https://book-review-ashy.vercel.app

---

## 📂 GitHub Repository

🔗 Repository: https://github.com/istewakhassantewak/Book-Review

---

## ✨ Features

- 📖 Browse book collection
- 📝 Read detailed book reviews
- 🔍 View book details dynamically
- 💾 Save books using localStorage
- 📌 Track reading preferences
- 🌐 React Router navigation system
- ⚛️ Component-based React architecture
- 🎨 Modern UI with Tailwind CSS + DaisyUI
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- React.js
- React Router DOM
- JavaScript (ES6+)
- Tailwind CSS
- DaisyUI
- HTML5
- Vite
- Fetch API
- LocalStorage API

## 📦 Installation & Setup

```bash
# Clone repository
git clone https://github.com/istewakhassantewak/Book-Review.git

# Navigate to project directory
cd Book-Review

# Install dependencies
npm install

# Run development server
npm run dev
🖥️ Build for Production
npm run build
